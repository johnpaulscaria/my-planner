PRIVACY
The private journal is encrypted in the browser with PBKDF2 + AES-GCM before being written to localStorage. The passphrase is not stored. If you forget it, the journal cannot be decrypted. The journal is stored on that browser/device and is not included in the existing Supabase planner sync. Export the encrypted vault regularly and store the backup safely. The browser's local storage is not a substitute for device security.

REMINDERS OUTSIDE THE APP
The website can show browser notifications while it is open and running. Static GitHub Pages cannot guarantee scheduled push notifications while fully closed. The app generates an .ics file with daily recurring reminders; download it and import it into Apple Calendar, Google Calendar or Outlook, then allow notifications in that calendar app.

BIBLE / ROSARY
The Daily Rosary section contains the customary weekday mysteries and common prayers. The Bible Reading section links to Catholic.org's current daily Mass readings and the USCCB calendar. It also creates a supplementary sequential Old Testament + New Testament chapter plan. The chapter plan is not the official daily Mass lectionary. Full daily Mass readings are opened on the source website.
